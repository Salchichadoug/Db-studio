# 🗄️ DB Studio - Gestor y Consultor Multi-Base de Datos

Aplicación web ligera diseñada para administrar, monitorear y consultar múltiples bases de datos (MySQL, PostgreSQL, MongoDB, SQLite y Redis) con persistencia local y consola de ejecución de consultas.

---

## 📋 1. Requisitos Previos

Al tratarse de una arquitectura cliente-ligero (*Single-File Web Application*), no requiere compilación ni instalación de dependencias pesadas de backend para su funcionamiento base.

* **Navegador Web moderno:** Chrome, Edge, Firefox o Safari (con soporte para ES6+ y `localStorage`).
* **Editor de código (Desarrollo):** Visual Studio Code (recomendado).
* **Para Despliegue Automatizado:** Docker / Docker Compose o cuenta en GitHub + Vercel/Netlify.
